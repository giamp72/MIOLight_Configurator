# MIODesign

Interfaccia web (HTML/JS statico, nessuna build) per la manutenzione dei dati di MIODesign, con database su Supabase. Il codice si trova in [`miodesign/`](miodesign/README.md); la pagina `index.html` della radice reindirizza all'applicazione. Three.js è incluso in `vendor/`.

Avvio locale: `python3 -m http.server 4174` e apertura di `http://localhost:4174/`. Setup di Supabase e funzioni: vedi `miodesign/README.md`.
